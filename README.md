# 🐘 Плодородный Слон — Премиальное органическое удобрение

[🌐 Посмотреть живой сайт](https://drinkbeer228.github.io/Elephantpoop/)

**Плодородный Слон** — это лендинг эко-бренда, производящего 100% натуральное органическое удобрение (биогумус) из навоза слонов. Продукт собирается вручную в Парке слонов в Сочи и ферментируется для безопасного применения в сельском хозяйстве.

---

- **История проекта** — как из навоза рождаются сувениры и бумага  
- **Почему это важно** — экология, сохранение деревьев и поддержка животных  
- **Пошаговый процесс** — от сбора материала до готового изделия  
- **Присоединяйтесь** — покупка сувениров или участие как инвестор  
- **Контакты** — как связаться с командой

## 💡 Особенности

- Адаптивный **лендинг на HTML + CSS**  
- Фоновые секции с изображениями  
- Плавная прокрутка и **scroll-driven анимации (CSS View Timelines)**  
- Lazy-loading изображений  
- Готовая SEO-структура и OpenGraph-теги  
- Fallback-анимации на старых браузерах через `IntersectionObserver`

---

## 🎨 Визуальная архитектура (Сторителлинг-скролл)

Сайт использует вертикальный бесшовный фон в стиле **Vignette / Side-focused composition** (современный 3D-эко-минимализм). 
Активные детали (листья, трава, корни, микрофлора) смещены к краям кадра, создавая естественную рамку. Центр остается чистым для идеальной читаемости текста и карточек (Glassmorphism).

* **Блок 1-2:** Светлый воздушный градиент, зелень по краям.
* **Блок 3 (Сравнение/Инструкция):** Темно-коричневый центр, фактурные корни по краям.
* **Блок 4 (Научный блок):** Глубокий темный фон, светящиеся золотистые сферы микроорганизмов на периферии.

## 🚀 Запуск (Деплой)

Проект не имеет зависимостей (Zero dependencies, Vanilla HTML/CSS/JS).

**Локальный запуск:**
- Просто откройте файл `index.html` в браузере
- Или используйте Live Server в VS Code для автоматической перезагрузки

**Деплой:**
- Любой статический хостинг (GitHub Pages, Netlify, Vercel)
- Просто загрузите файлы проекта
